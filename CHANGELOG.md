# Changelog

## v1.0 - July 2026 (Request for Comments)

Initial public release. Ten-point conformance test, reference architecture (six layers plus cross-cutting controls), eight principles: the Hybrid Context Stack, provenance metadata, open protocols (MCP/A2A), agent data contracts, agent identity, the autonomy ladder, the evaluation harness, and observability/governance mapping (OpenTelemetry GenAI, ISO/IEC 42001, NIST AI RMF).

Comment period: through October 1, 2026.

## v1.1 draft - July 2026 (in progress, revised in public during the comment period)

Added Section 3, "Who owns this architecture": the ownership model (PM owns / build partner constructs / PMO owns the standard, not the instances) and the verification guard - the PM verifies outputs, not pipes; if the PM can't check it, the build isn't done. Prompted by review feedback from **George Tohme** (CrashTestApps.DEV). Subsequent sections renumbered.
